# jiwookim.dev Personal Homepage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy Jiwoo Kim's bilingual (EN default, KO) job-search homepage: fixed profile sidebar + tabs, every detail behind a toggle, Ink & Rose design, real content from the CV.

**Architecture:** Astro 7 static site. Content lives in YAML files under `src/content/` (one file per item, English and Korean in the same file) and is loaded through content collections. Each tab is its own page (`/projects/`, `/ko/projects/`). Thin page files render shared "view" components that take `lang`. Pure helpers (i18n, sorting, dates, email encoding) are unit-tested with Vitest. A second test suite checks the built `dist/` output. GitHub Actions deploys to GitHub Pages under the custom domain.

**Tech Stack:** Astro 7.4.x, Vitest 5.x (plain `vitest/config`, node environment), TypeScript, `astro/zod`, `@fontsource/instrument-serif`, `@fontsource-variable/inter`, `pretendard`, `@fontsource/noto-serif-kr`, GitHub Actions (`withastro/action@v6`, `actions/deploy-pages@v5`).

**Spec:** `docs/superpowers/specs/2026-11-26-homepage-design.md` (approved 2026-11-26). Visual reference: `.superpowers/brainstorm/68175-1795669298/content/photo-layout-v2.html`, the **S3** block with palette class `p-ink`.

## Global Constraints

- Project root = this session folder. `git init` here. **Never commit** `source-materials/` (it holds the CV with the phone number and the original photo), `.superpowers/`, `node_modules/`, `dist/`, `.astro/`.
- Node ≥ 22.23.4, even-numbered (local is v26.10.0). Astro 7: set `compressHTML: true` so whitespace between inline tags survives.
- URLs: English at `/`, Korean at `/ko/`. Trailing slashes on every internal link (`/projects/`). `site: 'https://jiwookim.dev'`, no `base`.
- Menu order, exactly: About, Projects, Research, Experience, Beyond Work. There is no CV tab. The sidebar `CV ↓` button links to `/cv/Jiwoo_Kim_CV.pdf`, a copy of `source-materials/JIWOO_KIM_CV_public.pdf`.
- Colors (Ink & Rose, verbatim from spec 5.4):
  - sidebar bg `#1B2238`
  - sidebar text `#F2F2F5`; muted `rgba(242,242,245,.72)`; line `rgba(242,242,245,.18)`
  - rose accent `#E895A8`; secondary `#2D3A66`
  - main bg `#F6F6F8`; text `#1B2238`; muted `#6C7082`
  - line `#E0E1E8`; card `#FFFFFF`; chip `#E8E9F0`
- Type: Instrument Serif for the name and headings, Inter for the body. On `/ko/`, Pretendard is the body font and Noto Serif KR is the heading font. In the name, "Kim" is italic and rose.
- Photo: square ~176px, radius 4px, `box-shadow: 10px 10px 0 #E895A8`. It shows the full width of the photo with the face in the upper third (`object-fit: cover; object-position: 50% 50%` on the 800px-wide portrait). Swapping the photo means replacing one file.
- Toggles: native `<details>/<summary>`, closed by default. The `+` rotates 45° to `×` when open.
- Layout: desktop sidebar 300px, fixed. Only the main column scrolls. Below 768px the sidebar becomes a compact top header (photo 56px, name, CV button) plus a horizontal tab row.
- **Anti-goals:**
  - No charts, distribution curves, or statistical-symbol motifs anywhere.
  - No placeholder text in the built site.
  - No phone number.
  - No plain-text email address in HTML.
  - The sidebar must never say "Becoming a data scientist".
- Copy rules:
  - Sidebar title: `Data Scientist · Integrated M.S./Ph.D. Student`
  - Affiliation: `Statistics & Data Science, Yonsei University · Seoul`
  - Tagline: `Data scientist with ~3 years in industry, now researching graph anomaly detection.`
  - Only facts that appear in the CV. Never invent results, numbers, tools or values.
  - Korean copy is Claude's draft for the user to review.
- If an optional link (GitHub, LinkedIn, Scholar) is empty, its button is not rendered. If the `beyond` collection is empty, the Beyond Work tab and its pages are not generated.

## Review Focus

1. **Phone width (375px):** no horizontal scroll, the sidebar collapses to the header, and long project titles wrap inside their toggle. → visual check in Task 5.
2. **A Korean field is missing:** `/ko/` shows the English text for that field and does not render an empty string. → unit test in Task 1, dist test in Task 4.
3. **A deep link or refresh on GitHub Pages** (`/ko/research/`, or a mistyped URL) must not land on a blank page. → `404.astro` with a dist test in Task 4.
4. **JavaScript disabled:** the email is still reachable (a noscript fallback points to the CV), and toggles still work (native details). → dist test in Task 3.
5. **The photo leaks location metadata:** the published JPEG must carry no EXIF/GPS. → dist test in Task 3.
